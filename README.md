# JARVIS

Personal AI assistant. See `CLAUDE.md` for architecture, decisions, and the phase plan.

## Setup (Phase 2)

```bash
# 1. Create the virtual environment (already done if you're reading this after Phase 2)
python -m venv .venv

# 2. Activate it
.venv\Scripts\activate          # PowerShell / cmd
source .venv/Scripts/activate   # Git Bash

# 3. Install dependencies
pip install -r backend/requirements-dev.txt

# 4. Create your local secrets file (never commit this)
copy .env.example .env
```

## Run the server

```bash
cd backend
python -m uvicorn app.main:app --reload
```

Then visit `http://127.0.0.1:8000/health` — should return `{"status": "ok", ...}`.
Interactive API docs (auto-generated by FastAPI): `http://127.0.0.1:8000/docs`.

## Run the tests

```bash
cd backend
python -m pytest -v
```
